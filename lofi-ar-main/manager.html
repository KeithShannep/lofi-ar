LoFi Layers AR — Manager

Add one entry per AR print. When you click Build AR Site, every target image is compiled into a single targets.mind file (in the order below — Target 0, Target 1, …), your videos are matched up in assets/config.json, and everything is packaged into a ready-to-deploy zip.

This page reads local files, which only works when it's served over http(s). Open this folder with VS Code's Live Server (or run python3 -m http.server) instead of double-clicking manager.html.
